## 🛠️ How to Run

### Java (DAA)
```bash
cd DAA
javac src/<LabFolder>/<FileName>.java -d bin
java -cp bin <ClassName>
```

### C (OS Lab)
```bash
cd os_lab/<folder>
gcc <filename>.c -o output
./output
```

### Assembly (Assembly Lab)
```bash

# Use assembler tools depending on system (e.g., nasm, tasm)
```
